# Phase 5 — 어디서나(폰·노트북) 접속 + 고정 주소

앱 화면은 이미 반응형이라 폰·노트북 모두 잘 보인다(app.py / app_personal.py 의
모바일 CSS). 남은 건 **주소가 안 바뀌게** 하는 것 — 서버를 껐다 켜면 퍼블릭
IP가 바뀌어 매번 새 주소를 공유해야 하는 문제를 없앤다.

---

## 1. 반응형은 이미 됨 (확인만)
- 폰 브라우저로 `http://<서버IP>:8001` (app_personal) 또는 `:8503`(streamlit) 접속
- 메뉴·히어로·카드·채팅이 폰 폭에 맞게 접힘(세로 정렬), 터치 버튼 커짐
- → 추가 작업 없음. 안 맞는 화면이 있으면 알려주면 그 부분만 손봄.

---

## 2. ⭐ 고정 IP (Elastic IP) — 주소가 안 바뀌게 (핵심)

AWS는 인스턴스를 멈췄다 켜면 퍼블릭 IP가 바뀐다. **탄력적 IP(Elastic IP)**를
붙이면 고정된다. (계정당 실행 중 인스턴스에 붙은 EIP는 보통 무료)

AWS 콘솔:
```
EC2 → 탄력적 IP(Elastic IPs) → 탄력적 IP 주소 할당 → 할당
 → 방금 만든 IP 선택 → 작업 → 탄력적 IP 주소 연결
 → 인스턴스: novem 선택 → 연결
```
→ 이제 **껐다 켜도 같은 IP**. 그 IP로 폰·노트북 어디서나 접속.

> ⚠ 탄력적 IP를 할당만 하고 **인스턴스에 연결하지 않으면 요금**이 붙는다.
> 쓰지 않을 땐 '릴리스'로 반납.

---

## 3. (선택) 무료 도메인 — 숫자 대신 이름으로

IP(13.x.x.x) 대신 `daejeon-welfare.duckdns.org` 같은 이름으로 접속하려면:

**DuckDNS(무료):**
1. https://www.duckdns.org 에서 깃허브/구글로 로그인
2. 원하는 이름(subdomain) 만들기 → 현재 서버 IP 입력(Elastic IP면 고정)
3. → `http://<이름>.duckdns.org:8001` 로 접속

> 포트 없이(`http://…` 만으로) 열려면 80 포트 + Apache 리버스 프록시가 필요
> (deploy/DEPLOY.md 8번 참고). 발표용이면 `:8001` 붙여도 충분.

---

## 4. 폰·노트북 동시 접속 체크
- Elastic IP 연결 후, 노트북과 폰(셀룰러/다른 와이파이)에서 **같은 주소**로 접속
- 로그인 → 내 정보 → 맞춤 상담까지 양쪽에서 동일하게 동작
- (DB가 서버 MySQL이면 폰에서 가입한 계정이 노트북에서도 로그인됨 — 같은 DB)

---

## 5. 실제 서비스로 갈 때 (다음 단계, 참고)
| 항목 | 지금(프로토타입) | 실제 서비스 |
|---|---|---|
| 주소 | Elastic IP(+DuckDNS) | 정식 도메인(가비아 등) |
| 보안 | http | https(인증서, Let's Encrypt) |
| 포트 | :8001 | 80/443 (Apache 프록시) |
| 상시 가동 | nohup/systemd | systemd + 모니터링 |
